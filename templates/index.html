AIOStreams Desktop Flatpak remote

An unofficial, automatically refreshed Flatpak remote for the AIOStreams desktop app.

Add the remote

flatpak remote-add --if-not-exists --user aiostreams \
  @URL@aiostreams.flatpakrepo

Install

flatpak install --user aiostreams io.github.viren070.aiostreams

Update

flatpak update --user

Or let GNOME Software, KDE Discover, or your usual update service handle it.

This remote is not affiliated with the AIOStreams project. It mirrors the bundles published on GitHub Releases and signs the repository with its own key. The application ID is io.github.viren070.aiostreams.
